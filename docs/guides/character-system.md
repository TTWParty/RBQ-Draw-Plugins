# RBQ 角色系统手册：当前会话 / 角色库 / ⭐全局角色

> 适用：智能生图触发器 6.5.48 + 角色工坊 2.2.39，两个插件要一起更新。
>
> 第一部分「快速上手」够日常使用；第二部分「进阶说明」给想弄懂细节的人看。
>
> 本文里用「」括起来的，都是界面上按钮或提示的**原文**。像「编辑(角色库)」这样带括号的，括号也是按钮文字的一部分。

# 第一部分　快速上手

## ⚠️ 第 0 步：确认「启用角色外貌记忆」是开着的

不打开它，本手册讲的一切（当前会话、角色库、⭐全局角色、锁定、衣柜）都只是存着：角色工坊里照样能编辑、上锁、设全局，但**画图时一样都不会用上**。

- **新装插件**（智能生图触发器 6.5.48 起）：默认就是开着的。
- **以前装过的**：插件会保留你原来的设置，不会替你打开。旧版本默认是关的，所以很多老用户其实一直关着。

最快的检查办法：打开角色工坊。如果顶部有一条橙色提示「⚠️ 「角色外貌记忆」没有打开……」，就是关着的，点提示右边的「一键打开」即可（会自动保存）。没有这条提示就说明已经开着。

【截图：cw-memory-off】

也可以手动去看：

1. 打开 RBQ 生图控制台（打开方法见下面「〇」第 1 步）。
2. 在控制台左侧菜单点「智能触发」，再点上方的「设定与世界书」。
3. 找到「角色外貌记忆」这一栏，看「启用角色外貌记忆」（下图左边的红框）是不是开着。这个开关一点就自动保存，不用再点别的按钮。

【截图：appearance-memory】

这一栏其实就是「当前会话」的另一个入口，各部分的作用：

- **「参考角色卡信息（未建档时）」**（右边红框，默认开）：角色还没有档案时，让 AI 参考酒馆角色卡里的描述和世界书来定她的长相。这个开关也是一点就自动保存。
- **「当前已记忆角色」**：列出这个对话里记住的角色，就是角色工坊里的「当前会话」。每行依次是：名字；「🔒人设 / 🔓人设」「🔒衣服 / 🔓衣服」两个锁（点一下就能锁上或解开）；「(N套)」表示衣柜里有几套衣服；方括号里是她现在穿的衣服。从全局导入的角色还会多一个「⭐来自全局」。
- **「从角色卡提取 / 更新外貌」**：让 AI 读一遍当前角色卡，把她的长相存进这个对话。她身上已有的衣服不变。群聊里会弹窗让你选是群里哪位成员。人设已经锁上的话，长相不会被改，会提示「人设已锁定🔒，外貌没有被覆盖」。
- **「前往「角色工坊」深度定制与管理角色 (N 位)」**：直接跳到角色工坊。
- **「清空当前记忆」**：删掉**这个对话里**的全部角色，会先弹确认框。别的对话和⭐全局角色都不受影响；但只在这个对话里出现过的角色，角色库里也会跟着没了，确认框会列出是哪几位。

## 〇、在哪里打开

1. 打开 RBQ 生图控制台，以下任选一种：
    - 点酒馆左下角的三横杠菜单，选「RBQ生图」；
    - 点屏幕左侧的悬浮球，选「插件设置」；
    - 在酒馆的扩展面板里展开「RBQ生图扩展」，点「打开 RBQ 生图控制台」。
2. 在控制台左侧菜单点「角色工坊」。
3. 角色工坊顶部第一个标签页是「角色档案库」。下文的操作都在这里。

【截图：entry】

「角色档案库」上方有一排切换按钮：「当前会话 (N)」「角色库 (N)」「📖 同人库 (N)」。它们是同一页里的不同视图，点一下就切过去。页面里出现的「打开角色库」按钮，作用和点「角色库」切换按钮一样。

【截图：scope】

**衣柜在哪看**：每张角色卡上有一行「👗 当前: 某套衣服 (N套)」。点卡片上的「编辑」，在「差分衣柜 (N 套)」里能看到每一套衣服。「●穿」表示正在穿的那套，🔒 表示这套已锁住。

## 一、三个地方

- **当前会话**：这个对话里用的角色。AI 画图时会参考她们。
- **角色库**：所有对话里出现过的角色都在这里。同一个名字只显示一张卡。卡片标「仅存档」，AI 不会参考。
- **⭐全局角色**：在角色库里设出来，卡片标「⭐ 全局使用中」。每个对话里，AI 都会先拿到她的资料，所以她一出场就能认出来。她在剧情里出现时，会自动加到当前会话，并且锁住。

【截图：badges】

## 二、三件常用的事

**1. 让一个角色在所有对话里都一样**

1. 在某个对话里，把她的样子和衣服调到满意。
2. 在「当前会话」里点她卡片上的「编辑」。点「🔓 锁定人设」，变成「🔒 人设已锁定」就是锁上了。再在衣柜里选中那套衣服，点「🔓 锁定此衣服」，变成「🔒 服装已锁定」。最后点「💾 保存到 SDT 角色记忆」。
3. 点「角色库」切换按钮，找到她的卡（只有一张），点「设为全局角色」。

以后每个对话里她一出场，用的都是这一份。

> 必须先锁吗？不是必须，但建议锁。她在好几个对话里出现过时，系统会优先挑锁过的那份当全局版本；都没锁，就挑最早出现的那个对话里的那份，不一定是你刚调好的。角色库卡片上显示的，就是会被挑中的那份。

【截图：lock-before】【截图：lock-after】

【截图：set-global】

**2. 认错人了**

1. 她被自动加进当前会话时，会弹出提示「已从全局角色导入「X」到当前会话（人设与服装已锁定）」，后面有「撤销」按钮。这条提示**不会自己消失**，点 × 或点「撤销」才会关。
2. 点「撤销」：这个对话里会换成一张**同名、没上锁**的新卡，样子和衣服用的是这次剧情里描写的。全局角色本身不会变，这个对话以后也不会再导入她。
3. 以下情况没有「撤销」：
    - 已经关掉了提示；
    - 换到了别的对话；
    - 这条消息又点过「重新解析/刷新 tag」；
    - 正在用漫画模式（这时的提示几秒后会自己消失）。

    这时请在「当前会话」里点她的「编辑」，直接改样子和衣服后保存。注意：**删掉没用**，她下次出场会被重新导入。

【截图：undo-toast】

**3. 改角色**

- 在「当前会话」里点「编辑」：只改这个对话，别的对话不受影响。保存按钮旁也写着「只改本对话；要改所有对话请去角色库」。
- 想改所有对话：切到「角色库」，点「编辑(角色库)」（这就是按钮原文）。改的是角色库里那一份，以及从它导入到各对话的她；如果她是全局角色，改的就是全局版本。各对话里自己生成的同名角色不一定跟着变。保存时如果已有对话导入过她，会问「同时更新已导入的 N 个对话吗？」。
- 锁着也能改：锁只防止画图时被自动改动，你自己在编辑里改文字不用先解锁。

## 三、常见问题

**角色工坊好像不起作用？改了、锁了、设了全局，画出来还是不对？**
先检查第 0 步：「启用角色外貌记忆」开着没有。角色工坊顶部有橙色提示「⚠️ 「角色外貌记忆」没有打开……」就是关着，点「一键打开」；也可以去控制台左侧「智能触发」→「设定与世界书」→「角色外貌记忆」里看。它关着时，角色工坊里的改动都会保存，但画图时一样都不会用，⭐全局角色也不会自动导入。打开后，从下一次让 AI 读剧情（解析）开始生效；已经解析过的消息，要点「重新解析/刷新 tag」才会按新档案重画。

**新开对话，角色怎么都没了？**
都还在角色库里。点「打开角色库」，在想用的角色卡上点「导入当前」（意思是导入到当前会话）。

**「锁住」是什么意思？**
锁住的人设和那套衣服，画图时不会被自动改动。她在剧情里换上新衣服时，新衣服照样会作为新的一套加进衣柜。

**全局角色没出场时，会不会被画进不相干的图？**
插件会明确告诉 AI：没在剧情里出场的全局角色只作参考，不要凭空加进画面。所以一般不会。但这是给 AI 的要求，不是强制拦截。万一画进来了，按「认错人了」处理即可。

**插件怎么判断「是同一个人」？**
先看名字和别名，再看英文绘图名。英文绘图名要完全一致，作品名也算在内。作品名不同就当成两个人。一个名字同时对上好几位全局角色时，一位都不导入，以免认错。已有的角色不能在编辑里改名，想多几种叫法，就在「别名」里加。

**怎么只取消全局，不删角色？**
在「角色库」里点她卡片上的「取消全局角色」，确认「确定取消「X」的全局角色吗？」即可。角色本身和已经导入到各对话的她都会保留。千万别用删除按钮来取消。

【截图：cancel-global】

**「漫画模式」是什么？我在不在里面？**
漫画模式来自另一个插件「漫画模式」，它把一段剧情画成多格漫画页。没装这个插件就不用管。装了的话，在控制台左侧点「智能触发」，再点「提示词与破限」，看「漫画模式 (Manga Mode)」开关：开着就是在漫画模式里，这时「提示词预设档位」旁还会显示「漫画模式接管中」。另外，「触发与分镜」里的「前情增强分析」如果选了以「漫画」开头的选项，也按漫画模式处理。

**全局角色有数量限制吗？**
没有。但每次让 AI 读剧情、安排画面时，全局角色和她们的全部衣服都会一起发过去，越多，发出去的内容越长：等得更久，按用量计费的接口也会更花钱，AI 也可能抓不住重点。不常用的角色，建议不要设成全局。

**在角色库里删除会怎样？**
删除前会弹窗确认「确定从角色库中彻底删除角色「X」的档案记忆吗？」。确认后，所有对话里的她都会被删掉，全局角色也会一起取消，**不能恢复**。只想在这个对话里去掉她，请在「当前会话」里删除，弹窗是「确定从当前会话中移除角色「X」的档案记忆吗？」。这样只删这个对话里的她，别的对话和全局角色都不受影响。

**能备份吗？**
可以。点「导出备份」，会把当前视图里的角色存成一个文件；卡片上的导出小图标可以只导出一位。想把所有角色连同⭐全局角色一起备份，请切到「角色库」再点「导出备份」，备份里会记下谁是全局角色，只存在于全局的角色也在里面。要恢复时点「导入文件」：角色会导入到**当前会话**，备份里的⭐全局角色也会恢复成全局角色；如果你现在已经有同名、但内容不一样的全局角色，会先问你要不要用备份覆盖。

# 第二部分　进阶说明

> 这一部分会用到几个词：**解析**＝AI 读剧情、给出画图方案和角色资料的那一步；**LLM**＝做解析的那个 AI；**name_tag**＝角色编辑器里的「英文绘图名 (name_tag)」；**副本**＝复制到某个对话里的那一份档案。

## 1. 三层对照

| | 当前会话 | 角色库 | ⭐全局角色 |
|---|---|---|---|
| 是什么 | 这个对话自己的角色档案 | 所有对话档案的汇总，同名只显示一张 | 从角色库里挑出来、单独存的一份固定档案 |
| 会发给 LLM 吗 | 会 | **不会** | **会，每个对话都发**，连同全部服装 |
| 解析会改它吗 | 会，解析结果就写在这里 | 间接会（它只是汇总） | **永远不会** |
| 新开对话时 | 空的 | 不变 | 不变 |

> 表里「会发给 LLM」「解析会改它」都以「启用角色外貌记忆」开着为前提。关着时三层都不发、解析也不写，见第 9 节。

- 角色库**没有单独存一份**。所以 LLM 解析出的角色会"自动出现"在角色库里；某个角色只在一个对话里有档案时，在那个对话里删掉她，她也会从角色库消失（全局角色除外，全局本体单独存，仍显示在角色库）。
- 全局角色发给 LLM 的内容：人设/外貌、name_tag、别名、衣柜里的全部服装。导入到当前会话后，这份副本同样带全部服装发送（普通角色只发前 8 套）。

## 2. 设为 / 取消全局角色（细节）

- 点「设为全局角色」后提示「「X」已设为全局角色：任何会话都会发给 LLM，剧情中登场时自动导入当前会话并锁定」（「启用角色外貌记忆」关着时改为黄色提示「「X」已设为全局角色，但「角色外貌记忆」没有打开，现在还不会发给 LLM。点顶部「一键打开」后生效。」），卡片变成「⭐ 全局使用中」，排到最前面。角色库切换按钮显示为「角色库 (N) · ⭐M」，M 是全局角色数。
- 「取消全局角色」的完整确认文字：「确定取消「X」的全局角色吗？（之后不再自动发给 LLM；已导入各会话的副本保留不变）」。已导入的副本仍是锁定状态。
- **挑哪一份当全局本体**：同一角色在多个对话里有多份档案时，按顺序挑：① 真实档案优先（从全局导入来的副本不算）；② 锁定过的（人设或任一服装上了锁）优先；③ 都一样时选**最早建档**的那份。挑的不是最新的那份。
- **只看全局角色**：角色库工具栏的「只看全局角色 (M)」只显示全局角色；再点（按钮变成「显示全部角色」）恢复。
- **别名撞车提醒**：新设的全局角色与另一位全局角色有相同名字或别名时，提示「「某名」与⭐全局角色「某某」重复。剧情里出现这个名字时不会自动导入任何一位，请改掉其中一个别名。」

## 3. 自动导入（细节）

当解析出的角色是某位全局角色、当前会话里还没有她时：复制一份到当前会话 → 人设和所有服装锁定 → 弹出导入提示（第二行小字「锁定只是不让自动改写，在角色工坊里可以直接编辑；会话里的改动不会同步回全局」）。全局本体里"当前穿着"如果不在衣柜里，会作为一套锁定的「默认服装」补进衣柜。

- **认出导入的她**：「当前会话」卡片带「⭐ 来自全局」徽章，下面一行小字「🔒 锁定只是不让自动改写，在角色工坊里可以直接编辑；会话里的改动不会同步回全局」；智能生图触发器面板的角色列表里也有「⭐来自全局」徽章。
- **当前会话优先**：当前会话里已有她，就直接用这份，不会再导入第二份。
- **匹配规则**：先按剧情里的名字和别名找，找不到再按 LLM 给的 name_tag 原样比对；先查当前会话，再查全局角色。作品名不同就是不同的人，例如 `Saki (Nikke)` 和 `Saki (Blue Archive)`；皮肤/服装括号（如 `(swimsuit)`）不算作品名。
- **删掉还会回来**：在当前会话删掉导入的副本，她下次登场会被重新导入（没有"本对话不再导入"的开关）。要彻底不出现，就「取消全局角色」。
- 导入的副本锁着也能在编辑器里直接改文字；锁只挡解析和生图的自动改写。想让解析以后也能自动更新她，再点「🔒 人设已锁定」/「🔒 服装已锁定」解锁。

## 4. 「撤销」（细节）

只有普通的消息解析才带「撤销」。点了以后：删掉刚导入的锁定副本；用这次解析里 LLM 给出的人设和服装，在当前会话建一个同名、未锁定的普通角色，并把这条消息的生图卡片改绑到它；提示「已撤销：「X」改用本次解析的人设与服装（未锁定），重新生图会用它。全局角色没有改动」，原提示自动关闭。

**只显示普通提示（无「撤销」、几秒后消失）的情况**：漫画模式（含分层漫画、漫画工作室）；手动/测试解析；从角色卡提取外貌时触发的导入；在角色库手动点「导入当前」。

**撤销失败的提示**：

- 「已经切换到别的对话，无法撤销这次导入」：回到原来那个对话再点。
- 「找不到这次解析结果（可能已重新解析），无法撤销」：这条消息已经重新解析过。
- 「「X」已经是当前会话的独立角色了」：已经撤销过，或她已经不是导入副本。

**错过了撤销**：在「当前会话」里「编辑」手动改。注意这份副本仍算「来自全局」：以后在角色库保存这位全局角色并选择同步已导入的对话时，这里的人设会被改回全局版本。

## 5. 修改全局角色

在角色库点全局角色卡片的「编辑(角色库)」，编辑器标题带「📦 角色库模式」，改的就是全局本体，保存按钮是「💾 保存 (同步角色库)」。已有对话导入过她时，保存前会问：

> 同时更新已导入的 N 个对话吗？（这些对话里「X」的人设和来自全局的服装会改成这次保存的版本；各对话自己新增的服装保留。选「取消」则只改全局角色本体，已导入的对话保持原样）

- 「确定」：这些对话里的副本一起更新（仍锁定），各对话自己新增的衣服保留。
- 「取消」：只改全局本体，之后新导入她的对话才用新版本。
- 在角色库保存全局角色**不会**往你当前所在的对话里塞一份副本。

在「当前会话」里编辑，保存提示「「X」已保存到当前对话（其他对话和⭐全局角色不受影响）」。保存按钮旁小字里的「角色库」可以点：会关掉编辑器（**没保存的修改不会保存**）并切到角色库。

## 6. 角色库里的其他按钮

每张卡片根据当前会话里有没有她，显示其中一个：

- 「导入当前」（当前会话还没有她）：复制到当前会话。全局角色导入后人设与服装锁定。
- 「用全局版本覆盖当前」（当前会话已有同名角色）：先确认，再替换当前会话里那份；当前会话里解析出的新内容会被替换掉。全局角色用全局本体覆盖（锁定）；非全局角色用第 2 节规则挑出的那份覆盖。

**空对话提示**：「当前会话」为空而角色库有角色时，显示「当前会话暂无角色档案记忆。之前的角色都还在角色库里（N 位），可直接查看与导入。」和「打开角色库」按钮；有全局角色时还提示「已设 M 位⭐全局角色，剧情中登场时会自动导入当前会话。」

**批量管理**：点「批量管理」后可多选，然后「批量导入当前」「批量导出」「批量删除」。

**备份与恢复（细节）**：

- 「导出备份」导出**当前视图**：「当前会话」视图导出这个对话的角色；「角色库」视图导出各对话档案的汇总（每个名字一份）。
- 角色库视图的「导出备份」**包含⭐全局本体**：文件里多了 `globalCharacters`（每位全局角色的本体和设为全局的时间）和 `globalNames`（谁是全局角色），只存在于全局、没有任何对话副本的全局角色也在里面。导出提示会写「含 M 位⭐全局角色」。角色库视图的「批量导出」也会带上选中的全局角色。「当前会话」视图的导出不含这部分。
- 「导入文件」：档案总是导入到**当前会话**，同名角色会被文件内容覆盖。备份里有⭐全局角色时，同时恢复全局本体和全局标记；只存在于全局的角色不会被放进当前会话。和现有同名全局角色内容不同时，先弹一次确认（列出这些名字）：「确定」用备份覆盖，「取消」保留现有的这几位、其余照常导入；内容完全一样的直接跳过。
- 旧版备份文件（没有 `globalCharacters`）照常能导入，行为和以前一样。
- 卡片上的导出小图标（「导出该角色为独立 JSON 文件」）只导出这一位的档案，不带全局标记。
- **当前会话里删除**只删当前对话里的那份。当前对话里没有这个名字时什么都不删，并提示「当前会话里没有找到「X」，没有删除任何内容（其他对话不受影响）」。

## 7. 同一个角色出现在好几个对话里（尤其是原创角色）

- **每个对话各存一份、各自更新**：在哪个对话里解析，就只更新那份。
- **角色库只显示一张卡**，按第 2 节的规则挑，所以别的对话里刚解析出的新衣服，角色库里不一定看得到。想让它显示某一份，就把那份锁上。
- **在角色库编辑非全局角色并保存**：只同步**同一份档案复制出来的副本**（比如用「导入当前」复制过去的）；各对话里分别解析新建的档案算不同档案，不会被同步。未锁定的版本**不会覆盖**已锁定的版本。另外，当前所在的对话里也会写入（或更新）一份她。
- **推荐做法**：调到满意 → 锁上 → 设为全局角色（即第一部分「三件常用的事」第 1 件）。

## 8. 其他问答

**我在某个对话里改了导入的全局角色，其他对话会跟着变吗？** 不会，也不会同步回全局。

**取消全局角色后，已经导入的对话怎么办？** 副本保留不变，仍然锁定；只是新对话不会再自动导入她。

**两个全局角色叫同一个名字/别名怎么办？** 剧情里出现这个名字时两位都不导入。设为全局或保存时会提醒，把其中一个的别名改掉即可。

## 9. 「角色外貌记忆」面板与两个开关（细节）

位置：RBQ 生图控制台 → 左侧「智能触发」→ 上方「设定与世界书」→「角色外貌记忆」。

**「启用角色外貌记忆」关掉时，什么还管用、什么不管用**（6.5.48 起新装默认开；以前装过、保存过「关」的会保持关，不会被自动打开。关着时角色工坊顶部会一直显示橙色提示和「一键打开」按钮）：

| 功能 | 关掉时 |
|---|---|
| 解析时把角色长相/衣服写进当前会话 | **不写**。每张图只用这次 AI 现编的描述，前后不一致 |
| 把当前会话的角色档案、衣柜发给 LLM | **不发** |
| 把⭐全局角色发给 LLM | **不发** |
| ⭐全局角色登场时自动导入、弹「撤销」提示 | **不会发生** |
| 用锁定的人设/衣服、按衣柜预设换装 | **不起作用**（数据还在，只是不用） |
| 漫画模式（含分层漫画）读取和学习角色记忆 | **不读也不学** |
| 漫画工作台的「关联正文角色」 | 只带角色卡，**不带**角色记忆 |
| 角色工坊：编辑、上锁、换装、设为/取消全局、导入当前、导出/导入备份 | 照常能用，改动会保存，但画图时不会用 |
| 角色工坊：「🎨 测试单人立绘」「配动作生图」「🚀 立即演练生图」 | **照常能用**，它们直接拿档案里的文字去画，不经过这个开关 |
| 「从角色卡提取 / 更新外貌」（面板和角色工坊里都有） | **照常能用**，会写进当前会话；名字对上⭐全局角色时还会把她导入（只是之后画图不用） |
| 面板里的锁按钮、「清空当前记忆」 | 照常能用 |

所以「角色工坊不起作用」几乎都是这个开关没开。打开后不需要再点保存。

这一栏的两个开关都是**一点就自动保存**。面板里其他设置（接口、提示词等）改完才需要点「💾 保存智能触发器设置」，它在智能触发面板的**最上面**，紧挨着「启用插件」开关，往下翻页时也一直停在顶部。

**「参考角色卡信息（未建档时）」**（默认开）：

- 开着：解析时把酒馆当前角色卡（群聊则是本群所有成员的卡，不会拿别的卡）的描述和世界书一起发给 LLM，世界书只发和最近剧情关键词对得上（或没设关键词）的条目。「启用角色外貌记忆」也开着时，**当前会话里已经有长相档案的角色不再发**，只发还没建档的；外貌记忆关着时每次都发。
- 关掉：不发角色卡。「从角色卡提取 / 更新外貌」不受这个开关影响。
- 一点就自动保存（6.5.48 起；以前要点「💾 保存智能触发器设置」）。

**「从角色卡提取 / 更新外貌」**：

- 需要先在「接口连接」里配好 Tagger 接口，否则提示「请先配置智能生图的 Tagger 接口，再提取角色外貌」；角色卡没有描述也没有世界书时也会报错。
- 读哪张卡：单聊是当前打开的角色卡；群聊只在本群成员里选——只有一位成员就直接用她；在角色工坊编辑某位角色时点，会选名字对得上的那位成员；对不上或从面板里点时，弹窗「这是群聊：要从哪张角色卡提取外貌？」让你选，点「取消」什么都不改。
- 读角色卡描述和**全部**启用的世界书条目（不按关键词筛），让 AI 提炼长相、默认衣服和英文绘图名。
- 写进当前会话：长相会被替换（人设没锁时）；她已经有当前衣服的话衣服不变；头像和英文绘图名会更新。
- 人设已锁：长相不改，提示「「X」的人设已锁定🔒，外貌没有被覆盖（只更新了头像与绘图姓名）。如需改用角色卡外貌，请先在角色工坊解锁人设再提取。」
- 名字对上⭐全局角色、当前会话还没有她时，会先把她导入（锁定），所以通常会看到上面这条「人设已锁定」的提示。这次导入的提示没有「撤销」。

**「当前已记忆角色」**：只列当前会话里的角色（还没导入的⭐全局角色不在里面）。按钮上的「(N 位)」也只数当前会话。

**「清空当前记忆」**：确认框第一行「确定清空当前聊天的所有角色记忆吗？（共 N 位）」。如果有角色只存在于这个对话（不算⭐全局角色），下面会写「⚠️ 其中 M 位只存在于这个对话：「X」、「Y」……清空后这些角色也会从「角色库」里消失，且无法撤销」，并建议先「导出备份」或设为⭐全局角色；都在别处有存档时则说明「角色库」里仍能找到。完成后提示「当前聊天的角色外貌记忆已清空」。只清这个对话的档案（连同这个对话的漫画缓存）；其他对话的档案和⭐全局本体不动。清空后⭐全局角色再登场会被重新导入。
