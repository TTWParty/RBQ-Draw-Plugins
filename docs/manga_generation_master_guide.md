## 一、漫画单页底层物理定律：四维张力模型

任何漫画单页的本质，是在静态二维平面上构建**时间流、视线流、情绪差与空间深度**。

```
┌────────────────────────────────────────────────────────┐
│                      【漫画单页四维模型】                  │
│  1. 面积差 (Area Hierarchy)  ── 杜绝均分，确立绝对主格 │
│  2. 景别阶梯 (Shot Variance) ── 严禁同景并列，大开大合  │
│  3. 视线动线 (Visual Vectors)── 右上起手，反 Z 字落地   │
│  4. 声音与气泡 (Acoustic Flow)─ 视觉发声，与神态锁死    │
└────────────────────────────────────────────────────────┘
```

## 二、画格几何学：面积预算与版式拓扑法则

### 1. 黄金主格（Hero Panel / 決めコマ）绝对统治律
- **面积铁律**：一页必须有且仅有 **1 个核心主格，占据整页 45%～65% 面积**。
- **主格定位**：承载全页决定性时刻（重大动作爆发、核心体态呈现、关键台词宣告、惊人反转）。
- **辅助格定位**：占 10%～25% 面积，承担动机铺垫、次要动作、环境交代或局部反应。
- **严禁均分**：五五开（2格平分）、三等分（3格横切）、四等分（机械四格）会导致视觉焦点涣散，画面彻底失去戏剧张力。

### 2. 画格容量与格数预算（Panel Budget）
单页格数取决于叙事密度与画布尺寸（通常为竖版 832×1216 或横向跨页）：
- **1 格（Splash Page / 一枚絵）**：重大事件定格、极度震撼、章节封面级大场景。
- **2 格（Dynamic Split 7:3 / 6:4）**：因果对决、动作发起与受击、极度紧张的二元博弈。
- **3 格（Setup-Climax-Reaction）**：叙事标准节奏，1 铺垫 + 1 大主格 + 1 反应。
- **4 格非对称（Standard Manga Page）**：商业日漫连载主力结构（1 黄金主格 + 3 节奏辅助格）。
- **5~6 格（High-Density Action / Dialogue）**：极快节奏连招、多人密集辩论交锋。**注意：格数越多，每格人物细节与文字量必须按比例压缩，小格严禁塞长台词。**

### 3. 日漫标准反 Z 字视线动线（Reverse-Z Flow）
日漫从右往左翻页，视线流引导法则：
```
[右上：格1 初始视线切入] ───> [右中：格2 动作突进/阻断]
            │
            ▼
[左侧或横向：格3 黄金大主格 (占据视野重心与情绪高潮)]
            │
            ▼
[右下或左下：格4 情绪收束/悬念钩子 (引导翻至下一页)]
```

## 三、七级标准镜头景别矩阵（Camera Shot Hierarchy）

**镜头互斥铁律**：一页内**严禁连续出现同级景别**（例如严禁中景接中景）。必须在高低景别之间跳跃，制造呼吸感。

| 景别代号 | 英文提示词 | 取景范围与视觉职责 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **ELS / 大远景** | `extreme long shot, establishing shot, panoramic` | 宏大环境、建筑、荒野、战场全貌，角色呈微小剪影或点状 | 章节开篇、场景切换、孤立感/压迫感塑造 |
| **FS / 全景** | `full body shot, wide shot, head to toe` | 展现人物完整身形、立足点、全身服饰与空间站位 | 角色登场、决斗准备、双人体型差对比 |
| **MS / 中景** | `medium shot, waist up` | 膝盖或腰部以上，兼顾肢体动作与面部神态 | 武器挥击、施法、常规对话、肢体推拉动作 |
| **MCU / 中近景** | `medium close-up, chest up, bust shot` | 胸部以上，聚焦双肩姿态与清晰表情 | 情绪争执、说话者定格、心理防线松动 |
| **CU / 近景特写** | `close-up on face, headshot` | 头部至颈部，放大眼神、咬牙、冷汗、微表情 | 惊愕、愤怒爆发、羞耻破防、决意宣布 |
| **ECU / 极近大特写** | `extreme close-up on [eyes/mouth/finger]` | 局部五官：瞳孔骤缩、咬破唇角、颤抖双手 | 心理破防、致命线索发觉、痛苦/快感极限 |
| **Cut-in / 插入细节** | `insert shot, cut-in, macro close-up on [object]` | 关键道具、脚步蹬地、结合部位、指尖扣入肌肤 | 动作发力点、突袭切入、动作因果链连接 |

## 四、画框语言：出血、斜切与破框（Gutter & Border Dynamics）

商业漫画的画框不是被动的容器，而是情绪与速度的催化剂：

### 1. 经典边框模式（Gutter Styles）
- **全封闭白边（Fully Framed）**：`white border, fully framed panels`。四周带标准白边，格线分明。用于日常、文戏、严谨推理。
- **天地出血（Top-Bottom Bleed）**：`top-bottom bleed, narrow gutters`。天头地脚贴边无白边，内框紧凑。现代连载标准版式，沉浸感极强。
- **全幅粗墨线（Zero-White Border）**：`太い黒い仕切り線, 余白なし, tight panels`。无白色间隙，纯墨线切分，压迫感与对比度极高。

### 2. 动态斜切格（Slanted Panels / 斜めコマ）
- **提示词**：`slanted panels, dynamic angled frame, diagonal gutters`。
- **作用**：边框倾斜打破垂直重力感。用于：突发遇袭、高速冲刺、身体倾斜、情绪失控。

### 3. 破框法（Breaking the Frame / コマぶち抜き）
- **提示词**：`breaking the frame, dynamic foreground, weapon breaking border`。
- **作用**：角色肢体（拳脚、长发）或武器、光效突破外框边界，侵入相邻画格或留白区，产生跃出纸面的 3D 冲击力。

### 4. 回忆格与内心世界（Flashback & Mental Space）
- **提示词**：`black gutters, black border around panel, negative space`。
- **作用**：画格外部使用黑色底色填充（或虚线边框），直观标识时间线跃迁（回忆）或角色深层内心精神空间。

## 五、漫画视觉特效（FX）与网点图层系统（Speedlines, Screen Tones & Beta Black）

为了防止 AI 将漫画背景渲染为扁平灰度或伪 3D 渲染，必须主动注入日漫专用的视觉物理图层：

| 特效类型 | 日漫术语 | 核心提示词（Prompt Tokens） | 情绪与视觉机能 |
| :--- | :--- | :--- | :--- |
| **放射状集中线** | 集中線 (Shūchūsen) | `focus lines, radial speed lines, converging lines` | 视觉焦点强制锚定、惊愕、爆点爆发、绝顶冲击 |
| **平行速度线/流线** | 流線 (Nagaresen) | `speed lines, motion lines, horizontal speed lines, dynamic blur` | 高速位移、挥拳出击、抽送冲击、身体失衡倒下 |
| **手绘排线阴影** | カケアミ (Kakiami) | `cross-hatching, dense cross-hatching, pen hatching, dark hatching` | 心理阴暗面、绝望压抑、悬疑阴影、恐惧颤抖 |
| **大面积纯墨黑块** | ベタ塗り (Beta) | `solid black shadows, heavy beta, chiaroscuro, pure ink black` | 极端高对比度、暗部隐蔽、黑化、轮廓剪影 |
| **经典点状网点** | 網点トーン | `screentone, halftone patterns, manga dots, halftone shading` | 工业印刷质感、衣服质地、皮肤阴影过渡 |
| **情绪花背/闪光** | 花背 / 閃光 | `emotional floral background, sparkles, shojo sparkles, white flash` | 恋爱少女心跳动摇、高潮恍惚、白光过载 |
| **冲击破片与气浪** | 衝撃波・破片 | `impact sparks, shockwaves, debris flying, dust cloud` | 强力撞击、墙壁龟裂、肉体激烈碰撞 |
| **温热吐息与空气感** | 吐息・湯気 | `steamy breath, heavy panting haze, sweat drops flying` | 剧烈运动、本番急促喘息、体温失控蒸腾 |

## 六、多角色物理接触熔接法（Universal Contact Fusion）

### 1. 站桩失联的底层原因
当启用 Character Prompt 分槽时，模型如果只在各个角色槽里写单独动作（A: `standing`, B: `punching`），模型会将注意力头分配到画面两端，生成“两人各摆各的 Pose，中间隔着银河”的失败构图。

### 2. 物理接触三层熔接协议
任何涉及身体接触（抓握、推倒、拥抱、搏击打击、压制、体位交缠）的画格，必须严格执行：

```
[Layer 1: 全局 Base Caption 统领] 
── 强制注入双人空间相互作用词：
   grappling, physical contact, body contact, height difference, size difference,
   [pinned against wall / tackling / holding wrists / tight embrace]

[Layer 2: 支配方/主动方 Slot]
── 注入主动矢量与姿态：
   dominant stance, towering over, pressing forward, gripping [shoulder/collar], aggressive force

[Layer 3: 承受方/受动方 Slot]
── 注入受制状态与反作用力：
   submissive posture, pinned, struggling, arms restrained, pushed back, clenched posture

[Layer 4: 坐标体系 (use_coords)]
── 严禁拉开 X 轴距离！双人中心坐标必须设置为紧贴或重叠 (例如 x=0.48 与 x=0.52)。
```

## 七、气泡、拟音与全题材日式拟声词权威词典（SFX & Onomatopoeia Matrix）

### 1. 标准气泡形状指令表
| 气泡功能 | 准确指令 | 视觉形态 | 对应情绪/语境 |
| :--- | :--- | :--- | :--- |
| **标准对话** | `BubbleType: 通常吹き出し` | 光滑椭圆气泡 + 尖角尾巴 | 平静陈述、说明、日常问答 |
| **大声咆哮/破音** | `BubbleType: 叫び吹き出し` | 边缘炸裂剧烈锯齿 | 战吼、怒斥、惊呼、破防抗拒 |
| **内心思考** | `BubbleType: 思考の吹き出し` | 云朵波浪边缘 + 连续圆圈尾巴 | 心声独白、暗自盘算、羞耻暗想 |
| **颤抖/虚脱** | `BubbleType: 波打つ吹き出し` | 边缘如波浪抖动的软气泡 | 恐惧战栗、受创呻吟、娇喘断续、哽咽 |
| **耳语/微弱** | `BubbleType: 破線吹き出し` | 虚线勾勒边框 | 咬耳朵密谋、垂死低语、自言自语 |
| **机械/旁白** | `BubbleType: ナレーション枠` | 矩形直角方框 | 场景交代、时间跃迁、画外旁白解说 |
| **纯拟声词** | `SFX: 擬音, 吹き出しなし` | **无边框**，纯美术字嵌在画内 | 脚步声、雷鸣、心跳、喘息、金属碰撞 |

### 2. 排版方向与位置映射
- **排版指令**：
  - `Layout: 縦書き`（**强烈推荐**：传统日漫竖排，字形最协调，出字率最高）
  - `Layout: 横書き`（横排：适合纯拟音或英文拟声如 BOOM、CRASH）
- **锚定位置**：`右上`, `左上`, `右下`, `左下`, `口元`（角色嘴边）, `画面外`（画外发声）, `頭上`。

### 3. 多气泡语法规则（连续双换行隔开）
```text
BubbleType: 通常吹き出し, 右上, Layout: 縦書き,
BubbleType: 叫び吹き出し, 左上, Layout: 縦書き,
SFX: 擬音, 吹き出しなし, Layout: 縦書き
Text: ドクン...

ようやく追い詰めたぞ。

諦めるものか……！
```

### 4. 全题材日漫高频拟声词（オノマトペ）权威分类词典
在 AI 生成中，纯拟声词必须通过 `SFX: 擬音, 吹き出しなし` 注入日文字符，才能获得最纯正的连环画质感：

#### A. 战斗动作与物理冲击类
- **ドカッ / バシッ**：重拳命中 / 掌掴脆响
- **ズバッ / ザシュッ**：利刃斩击 / 剑气切开肉体
- **ドォォン / ドガアアン**：剧烈大爆炸 / 建筑坍塌
- **ゴゴゴ (Gogogo)**：荒木风重压、威压感、地鸣震颤
- **ドドド (Dododo)**：千军万马奔袭 / 连续疾风骤雨般连打
- **ガキィン**：金属武器正面火花碰撞
- **ザッ**：急速刹停 / 突击蹬地起步

#### B. 心理悬疑与恐惧惊觉类
- **ドクン / ドクンドクン**：心脏猛烈跳动、惊骇、心悸
- **ゾクッ**：恶寒直冲脊背、恐惧触电感
- **ギクッ**：心虚、谎言被当面拆穿
- **ハッ**：猛然回过神来、察觉危险
- **ゴクリ**：紧张吞咽唾沫

#### C. 日常生活与肢体接触类
- **サッ**：敏捷抽身、迅速避让
- **スッ**：无声无息地靠近、悄然伸出手
- **ガタッ**：椅子猛然后推、桌具碰撞
- **バタン**：重重甩门、身体倒地
- **フワッ**：裙摆或长发随微风轻柔飘起

#### D. 同人本 / 感官漫画专精拟声词库（核心生产力）
- **ヌプッ / ズブッ**：进入、沉没插入的湿润阻滞感
- **ズチュッ / ズリュッ**：深层深入推进时的紧致声
- **クチュクチュ / ヌチュヌチュ**：体液交融、湿润摩擦的声音
- **ビチャッ / ビシャッ**：爱液飞溅、剧烈水声
- **パンパン / パァン**：抽送时下腹与臀部剧烈拍击的肉体碰撞声
- **ビクンビクン / ピクピク**：高潮绝顶时的强烈痉挛、颤抖抽搐
- **はぁ...はぁ...**：灼热急促的呼吸喘息
- **んっ...あっ... / ひぅっ...**：隐忍呻吟与敏感破音

## 八、日漫符号化微表情与生理反馈矩阵（Iconographic Micro-Expressions）

日漫的灵魂在于极具提炼感的“符号化表情”。在 AI 提示词中直译这些日漫符号，能瞬间唤醒模型的二次元夸张画力：

| 情绪/状态 | 符号化视觉特征 | 核心提示词（Prompt Tokens） |
| :--- | :--- | :--- |
| **极度羞耻与动摇** | 脸颊双道斜线红晕、眼神游移、咬紧下唇 | `blush stickers, hatched blush lines, averted gaze, biting lower lip, embarrassed blush` |
| **绝望与黑化** | 双眼被黑色阴影笼罩、面无表情、高光消失 | `face darkened by shadows, shadowed eyes, lifeless eyes, empty gaze, emotionless` |
| **感官沉沦 / 绝顶** | 瞳孔化作心形、白眼上翻、嘴角溢涎、微张双唇 | `heart-shaped pupils, heart eyes, rolling eyes, tongue out, drooling, slack-jawed, ahegao tendency` |
| **暴怒与强忍** | 额头或太阳穴爆起十字青筋、咬牙切齿、眼神如刀 | `popping veins, cross popping vein on forehead, clenched teeth, furious glare, burning eyes` |
| **失神与休克** | 瞳孔完全留白（白目）、身体瘫软、下巴脱力 | `blank white eyes, dilated blank pupils, completely unfocused eyes, jaw slack` |
| **委屈与被动屈服** | 眼角蓄泪泛光、泪水滑落脸颊、强忍抽噎 | `tears welling up in eyes, tears streaming down cheeks, tearful gaze, quivering lips` |
| **心虚与极度恐慌** | 太阳穴或脸侧挂巨大蓝色/黑色汗滴、瞳孔骤缩 | `sweat drop on cheek, oversized sweatdrop, contracted pupils, trembling posture` |
| **眩晕与混乱** | 蚊香螺旋眼、嘴巴变成波浪状 | `spiral eyes, dizzy eyes, wavy mouth, utterly flustered` |

## 九、同人本 / 感官漫画专门导演学与八页推进链（Eromanga Aesthetics & 8-Page Scene Arc）

### 1. 「无遮挡构图律」（Simultaneous Visibility）
同人本严禁“男方后背把女方挡得严严实实”。必须采用以下三大黄金夹角：
- **过肩侧俯视（Over-the-Shoulder 3/4 High Angle）**：从肩膀侧上方俯瞰，**同时看清女主角面部表情与身体接触部位**。
- **贴身侧切平视（Dutch Angle Profile）**：镜头贴近地面或床面，45度斜角切入，展现两人体型差与背部弓起的身体曲线。
- **俯视大三角构图（High Angle Overhead Triangle）**：从正上方俯视，两人肢体纠缠、散乱在床单上的长发、褶皱衣物一览无余。

### 2. 「拔コマ」呼吸交替法（Contrast Pacing）
在感官互动的高潮阶段，画格绝对不能单一重复同一姿态，必须严格交替三种画格：
1. **见せコマ（全貌主格 50%~55%）**：展示核心体位、体型悬殊、肢体交缠全貌（`interlocking limbs, disheveled clothes, sweat`）。
2. **抜きコマ A（生理/动作/结合部微距切入 20%~25%）**：极近特写——身体交汇处的接触极近微距（`macro close-up on interlocking physical contact, overlapping silhouettes, body fluids`）、双手死死抓皱床单（`fingers digging into sheets`）、脚趾发白蜷缩（`curled toes`）。
3. **抜きコマ B（面部神态破防 20%~25%）**：脸部大特写（阿黑颜倾向）——眼神迷离上翻、脸颊红晕贴纸、嘴唇微张微喘、泪水与口水（`flushed face, parted lips, heavy breathing, blush stickers, rolling eyes, tears, drool`）。

### 3. 本子三大经典单页蓝图（Blueprints）
- **蓝图 A：【强推 / 逼近 / 破防页】（The Cornering Page）**：右上回眸察觉（15%） + 右中抓扣肩膀 Cut-in（15%） + 左侧单边贯通贴墙体格压制主格（55%） + 右下咬牙屈辱特写（15%）。
- **蓝图 B：【本番抽送型 / 核心推进页】（The Interlocking Page）**：经典三段式闭环：**体位主格（50%） -> 结合部微距（25%） -> 阿黑颜面部破防（25%）**。
- **蓝图 C：【高潮爆发 / 余韵瘫软页】（The Climax & Afterglow）**：上方斜切爆发主格（65%） + 下方横向长条余韵格（35%）。

### 4. 商业级感官场景八页宏观推进链（The 8-Page Scene Formula）
当需要将一段小说或剧本转化为整场 8 页连贯漫画时，遵循以下镜头进阶链：

```
[Page 1: 危机潜伏与前摇破裂] ── ELS 环境交代 + 察觉危险回眸 + 突然逼近的身影
       │
       ▼
[Page 2: 物理角力与空间封死] ── FS 逃跑受阻 + 扣住手腕 Cut-in + 贴墙单边贯通大压制
       │
       ▼
[Page 3: 衣物破损与屈辱动摇] ── MCU 撕扯衣角 + 锁骨冷汗 + 咬牙偏头特写 (阶梯1->2破防)
       │
       ▼
[Page 4: 彻底推倒与前戏发酵] ── 俯视大三角推倒 + 指尖试探触碰 Cut-in + 娇喘与战栗气泡
       │
       ▼
[Page 5: 本番启动与初次贯通] ── 蓝图B闭环: 体位大主格 + 结合部微距插入 + 瞳孔骤缩特写
       │

       │

       │
       ▼
[Page 8: 虚脱余韵与下回诱饵] ── 横向大长条软瘫 + 心形瞳孔散失 + 抚摸秀发 + 翻页悬念
```

## 十、全题材通用剧作节拍模型与分镜决策树（Decision Tree）

面对任意一段剧本/剧情小说，按以下决策树进行单页工程转化：

```
                    【输入原始剧本】
                           │
                           ▼
              [步骤 1: 提炼本页唯一核心爆点 (Beat Peak)]
       (是致命一击? 惊人秘密? 物理压制? 深度交缠? 还是深情对视?)
                           │
                           ▼
              [步骤 2: 锚定黄金主格 (Hero Panel)]
    - 将 45%~65% 面积分配给该瞬间，选定画幅(纵向/横向/斜切)
                           │
                           ▼
              [步骤 3: 逆推铺垫格与反应格 (Shot Ladder)]
    - 起手格: ELS/FS 交代环境或动作前摇 (10%~20%)
    - 切入格: Cut-in 特写手部/武器/结合部/局部触碰 (10%~25%)
    - 终末格: ECU 面部情绪定格 (咬牙/震颤/阿黑颜) (10%~25%)
                           │
                           ▼
              [步骤 4: 物理接触判定 (Contact Check)]
    - 是否存在接触纠缠? 
      ├─ 是 ──> 启动 Contact Fusion: 动作词并入 Base Caption, 坐标聚拢
      └─ 否 ──> 保持空间对峙, 视线矢量相对
                           │
                           ▼
              [步骤 5: 声音与特效赋能 (Audio & FX)]
    - 特效注入: 集中线 / 速度线 / 网点 / 排线
    - 拟音走 SFX 吹き出しなし (脚步、撞击、肉体碰撞声)
    - 情绪台词对齐 BubbleType (叫び / 思考 / 波打つ)
```

## 十二、工业级通用 Negative Prompt 母版与零翻车终审清单（Checklist & Negative Template）

### 1. 工业级推荐 Negative Prompt 标准母版
为了防止模型把日漫风格画成拟真 3D、混色插画或破裂画格，建议在生图时使用以下标准负面提示词：

```text
colored, color, full color, 3d, realistic, photorealistic, bad anatomy, deformed limbs, extra fingers, missing fingers, malformed hands, blurry, bad lineart, missing panel borders, broken panels, text watermark, artist logo, bad screentone, messy border
```
*(注意：严禁在 Negative Prompt 中加入 `comic`, `manga`, `speech bubble`, `text` 等词，否则会直接摧毁画格切分与文字气泡引擎！)*

### 2. 生图前 10 项终审避雷清单
- [ ] **1. 面积统治校验**：是否存在一个占 45%~65% 的绝对黄金主格？（严禁均分）
- [ ] **2. 景别互斥校验**：相邻画格景别是否跳跃？（严禁连续两个中景）
- [ ] **3. 无遮挡构图校验**：双人互动时，是否采用了过肩3/4角、侧切角或俯视，确保表情与肢体清晰可见？
- [ ] **4. 接触熔接校验**：肢体纠缠时，交互动词是否已并入 Base Caption？双人坐标是否紧贴？
- [ ] **5. 特效图层校验**：是否根据动作激烈程度注入了集中线（`focus lines`）、速度线（`speed lines`）或排线（`cross-hatching`）？
- [ ] **6. 符号化表情校验**：面部神态是否使用了具有二次元辨识度的标签（如 `blush stickers`, `shadowed eyes`, `heart-shaped pupils`）？
- [ ] **7. 纯拟音与娇喘标记**：不需要白框的拟音，是否标记为 `SFX: 擬音, 吹き出しなし` 且内容使用纯正日文拟声词？
- [ ] **8. 气泡语法对齐**：`BubbleType` 声明顺序与数量，是否与 `Text:` 中的两空行（`\n\n`）隔开的文本完全一一对应？
- [ ] **9. 负面词清洗**：Negative Prompt 是否已排除 `comic`、`text`、`speech bubble` 等违禁词？
- [ ] **10. 翻页悬念锚定**：左下角末尾格是否具备引导翻页的动作前摇或情绪悬念？
