社区共享、署名与下架声明

1. 公益分享 · 非商业性质

本工坊为 SillyTavern & RBQ 生图社区公益交流平台，站内所有画师串、参数预设与基准预览图均免费开放浏览、参考与导入使用，不用于商业售卖，亦不对社区投稿内容主张版权。

2. 来源与署名说明

预设来源于社区用户自主投稿及公开渠道整理归档；署名含「整理」者仅代表搜集归档与基准封面制作，并非原始调串作者或画师本人。保留原有命名与作者代号旨在尊重来源，不代表原作者背书。

3. 原作者权益与快速下架通道

• 自助管理：创作者可凭个人码在「创作者中心 → 我的上传」随时在线编辑或永久下架自己的作品。
• 侵权 / 异议处理：如您是某预设的原始作者或整理者，不希望作品在本站展示或需更正署名，请通过 GitHub Issues 提交对应预设标题 / ID，管理员核实后将第一时间下架或修正。

4. AI 生成内容与使用责任

本站预览封面均由 AI 模型依据公开提示词渲染生成，仅作风格与参数效果研究参考；使用与二次分发请遵守所在地法律法规及对应生图模型条款，切勿用于侵权、违法或商业倒卖用途。
