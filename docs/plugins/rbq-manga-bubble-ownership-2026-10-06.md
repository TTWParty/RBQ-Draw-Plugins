# 结构化气泡归属检查记录

日期：2026-10-06。版本：漫画 **1.9.27**、SDT **6.5.17**。

## 样本能确认什么

检查用户指出的 `rbq_nai_20261006_171327.png` 所保存的最终绘图数据：画布 832×1216，3 组气泡说明和文字集中在全局 `base_caption`；6 条人物字幕均没有 `Text:`。绘图身份也存在同名关联与不同外貌的冲突迹象。

这能确认送往绘图模型的文字已经处于整页层。PNG 未保留原始模型响应的 `page/panels/characters`、解析版本、对白模式和入口，因此不能仅凭成图确认它源自模型错误、格式迁移还是某次编辑，也不能把所有画面问题归因于同一处代码。本记录不保存或复用样本剧情，所有实现与回归使用普通办公、递信和对话夹具。

## 已复现的通用漏洞

给一格配置两位可见人物，将一句普通对白放入格级 `bubbles`，两位人物各自 `bubbles: []`。旧编译器把台词拼进全局 Text，两位人物字幕没有台词，而且警告为空。将人物对白放到页级也有同样问题。旧 Schema 在三个层级都允许全部气泡类型，中文提示要求“对白归本人”，程序却没有对应归属校验。

这与正确结构化响应的行为不同：台词放入各自 `characters[].bubbles` 后，现有编译器会把它们写入对应人物字幕，并保留顺序、字面内容、类型、位置和排版。问题不是所有气泡数组都会被拼错，而是明确放错层级的响应仍被当成有效数据。

另有独立的身份连续性问题：普通夹具中，两条不同 `character_id` 使用完全相同姓名而返回冲突外貌，姓名关联状态会复用首次外貌。现有设计允许同一人跨格复用姓名、局部编号变化与状态延续，不能简单凭编号不同或字符串不同就认定是另一个人。本次没有自动猜测或重写身份；原始模型响应仍是查明具体错配所需证据。

## 本次规则

| 文字层级 | 允许内容 | 明确错误 |
| --- | --- | --- |
| `page.bubbles` | 整页 `caption/sfx` | 人物对白、心声、某一格的画外回答 |
| `panel.bubbles` | 本格 `caption/sfx/offscreen/broadcast/tailless`；显式 `position=offscreen` 的 `speech/screaming/whisper/shiver/connected` | 心声；未声明画外位置的普通人物对白 |
| `characters[].bubbles` | 对应人物的对白类型、心声等 | `caption/sfx` |

Schema 对明显不合法的类型设置各层 enum；类型与位置组合由共用运行时校验检查。真正画外的耳语仍可用 `whisper` 虚线形状，不必强行改成另一种气泡。现有日文类型/位置别名、默认元数据和空文字跳过行为继续兼容；非法字段仍由结构校验诊断。

只检查明确的字段错误，不能判断一条普通文字实际是谁说的，也不能发现所有把人物台词伪装成旁白或无尾声音的语义错误。

## 响应与编辑行为

1. **新正文解析、新工作台分镜**：校验全部页面；任一页有明确错误则拒绝整次响应，附原始页树 JSON，不写入本次角色记忆/灰阶缓存，不提交生图，不自动重试。
2. **AI 润色、微调后重绘**：对照输入页树，允许原样继承已有错位气泡，保留手动修正入口。新添加、复制、移动到其他层级/画格或修改后仍错位的文字拒绝提交。比较包括所属页面、画格、人物身份、类型、位置、排版和字面文字，重复气泡按数量核对。
3. **旧缓存、已有草稿、手动编辑**：兼容编译并保留文字，不猜说话者或自动搬移；输出明确警告。显式 `[]` 仍能清空文字。新响应携带空数组和旧格式 Text 的既有恢复规则保留。
4. **诊断展示**：工作台提示栏与提交提示展示编译警告；SDT 按页诊断保留警告。主解析错误界面保留 `error.rawOutput`，与已有接口调试信息共同展示，避免把有效错误响应误报为没有正文。

新版漫画校验 API 与新版 SDT 配套；旧漫画插件不提供新 API 时，SDT 维持原有兼容行为。因此需要同时更新两插件并刷新酒馆。

## 验证与剩余限制

最终 **30 个漫画与 SDT 回归脚本、690 项检查全部通过**；其中新增 28 项气泡归属与 11 项 SDT 诊断检查。生产文件和新测试语法、版本清单与差异检查通过。

测试执行生产 Schema、响应归一化、正文/工具/自定义 HTTP 请求、NAI 请求钩子和工作台处理函数。接口返回使用中性模拟响应，未调用真实解析模型或生图服务。验证包括正确人物归属、显式画外声、旧缓存保留、新响应原子失败、原始输出展示、工作台警告显示与微调失败后可继续修改提交。

页级与格级非人物文字仍按原版协议压平到全局字幕，其格位约束主要来自提示词；本次没有实现本地气泡坐标排版。程序校验通过不能保证模型的语义选材、身份识别、动作解剖或文字绘制成功率。重新解析才能产生新分镜，重绘旧结果不会自动修复归属。
