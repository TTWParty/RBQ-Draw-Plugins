# Grok 生图插件 (Grok Draw)

插件 ID：`rbq-grok-draw`

入口文件：[`../../plugins/grok-draw.js`](../../plugins/grok-draw.js)

---

## 功能简介

Grok 生图插件为 RBQ 生图扩展引入了 xAI Grok 的高品质生图与图像重绘能力。

通过调用 xAI 兼容的 Image Edits API（如 `grok-2-image`），自动将提示词和上下文画面渲染为富有质感的现代画风。

---

## 主要特性

- **独立生图模式**：在 RBQ 控制台【当前模式】下拉菜单中新增 `Grok` 选项。
- **自定义比例与分辨率**：
  - **比例支持**：`1:1`、`3:4`、`4:3`、`9:16`、`16:9`。
  - **画质支持**：`1K 标准高清`、`2K 超清分辨率`。
- **动态透明画布生成**：内置纯前端 Offscreen Canvas 生成与比例适配算法，自动对齐目标画布尺寸。
- **兼容自定义中转接口**：支持配置自定义反代 Endpoint、API Key 及模型名称。

---

## 配置说明

在 RBQ 控制台切换为 **`Grok`** 模式后，可在面板中配置：

| 配置项 | 说明 | 示例 |
|---|---|---|
| **API 地址** | xAI 官方或第三方中转地址 | `https://api.x.ai/v1/images/edits` |
| **API Key** | 授权密钥 | `xai-xxxxxxxx` |
| **模型名称** | 生图模型代号 | `grok-2-image` |
| **图像比例** | 画布宽高比 | `1:1`、`9:16`、`16:9` 等 |
| **分辨率** | 画质分辨率 | `1K` 或 `2K` |
