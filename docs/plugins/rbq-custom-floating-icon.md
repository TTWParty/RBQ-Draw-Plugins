# 摸鱼悬浮球 (Slack-off Floating Ball)

插件 ID：`rbq-custom-floating-icon`

入口文件：[`../../plugins/custom-floating-icon.js`](../../plugins/custom-floating-icon.js)

---

## 功能简介

摸鱼悬浮球插件将 RBQ 生图扩展默认的右下角悬浮球样式替换为超可爱的摸鱼猫咪图标，并带有流畅的放大和偏转微动画。

---

## 主要特性

- **可爱猫咪视觉**：使用高清 Base64 内嵌的猫咪立绘图标替换默认图标。
- **平滑物理微动画**：
  - **悬停 (Hover)**：放大 1.12 倍并轻微顺时针偏转 4°，伴随粉色柔光扩散投影。
  - **按下 (Active)**：微缩小至 0.92 倍，营造 Q 弹的按压反馈。
- **即装即用**：纯 CSS 注入机制，无需复杂配置，安装并刷新后立即生效。

---

## 安装与使用

1. 打开 RBQ 生图扩展控制台 ➔ 切换到 **【子插件中心】**。
2. 找到 **摸鱼悬浮球** 并点击 **安装**。
3. 按 `Ctrl + F5`（Mac 按 `Cmd + Shift + R`）刷新页面即可看到全新猫咪悬浮球。
