## 🌟 功能简介

本插件专为多设备（PC / 手机 / 平板 / 局域网酒馆）打造，解决大图片吃满手机流量、IndexedDB 跨设备无法同步、以及酒馆服务端磁盘膨胀的难题。

核心机制采用**双轨省流云同步**：
1. **轻量预览流媒体（默认）**：出图后在后台静默将原图压缩为 ~50KB 高保真 WebP 预览图上传至酒馆服务端，正文内联卡片与画廊多端极速秒开，极大节省移动端流量。
2. **收藏自动同步无损原画**：用户只要在大图查看器或消息中点击「⭐ 收藏」，插件立即自动提取原画（PNG/WebP），无损上传持久化至酒馆服务端，实现“省流出图，按需收藏”。
3. **跨设备自动补传**：在手机端收藏了图片后，消息背包（`extra`）自动同步收藏标记；切回拥有本地原图缓存的电脑端时，后台自动检测并静默补传无损原图，全程无需手动干预。
4. **大图查看器存储状态感知**：大图右上角微型圆点实时指示当前图片的物理存储归属（🟢 服务端高清原画 / 🟡 服务端省流预览 / 🔵 本地 IndexedDB 缓存 / 🟣 ComfyUI 临时链接 / ⚪ 内存链接）。点击圆点即可呼出精致的居中模态框，直观查看尺寸、物理路径、多端状态，并支持一键补传或单键复制。

## ⚙️ 配置说明

在 RBQ 设置面板的「图库云同步」专属 Tab 页中，可自由配置以下项：

| 配置项 | 默认值 | 作用说明 |
|---|---|---|
| **同步模式 (`syncMode`)** | `stream_only` (仅预览图) | **本地模式**：完全依赖本地 IndexedDB，不上传服务端；<br>**仅预览图**：仅上传轻量 WebP 预览图（最推荐，兼顾省流与速度）；<br>**全量原图**：每次生图都完整上传无损原画。 |
| **收藏自动同步原图** | 开启 (`true`) | 只要将任意图片标记为收藏，后台全自动补传无损原画至服务端。 |
| **查看器存储状态指示灯** | 开启 (`true`) | 在大图查看器右上角显示微型状态圆点，点击查看存储归属与物理路径详情。 |
| **省流模式感知** | 开启 (`true`) | 检测到手机移动蜂窝数据网络时，自动降低预览图上传与拉取画质。 |
| **预览图最大分辨率** | `768` px | 自动等比缩放生成轻量预览图的最大边长。 |
| **预览图压缩质量** | `0.8` (80%) | WebP 预览图画质压缩比，50KB 即可达到原图级观感。 |

## 🔍 大图查看器交互细节

当开启「大图查看器指示灯」后，查看任意生成图片时：
- **右上角圆点颜色**：
  - 🟢 **绿色**：酒馆服务端无损原图（已完全入库持久化，跨设备永不丢失）
  - 🟡 **黄色**：酒馆服务端轻量 WebP 预览图（多端秒开省流，可通过点击底部胶囊或收藏拉取原画）
  - 🔵 **蓝色**：仅当前设备本地 IndexedDB 缓存（换设备或清除浏览器缓存可能失效）
  - 🟣 **紫色**：ComfyUI / 外部后端临时预览地址
  - ⚪ **灰色**：纯内存临时链接
- **点击圆点弹出的模态框**：
  - 展示物理存储路径 / URL（带代码框与一键复制按钮）
  - 展示规格尺寸与真实文件体积
  - 若为本地缓存或省流预览图，面板内直接提供 **「一键同步至酒馆服务端」** / **「上传高清原画至酒馆」** 快捷动作，上传成功后即时自愈并刷新指示灯状态！

## 🔌 开放 API 接口 (`RBQ.api.gallerySync`)

宿主通过 `RBQ.api.gallerySync` 暴露底层工具函数，供其他子插件自由调用：

```javascript
// 1. 深度检测任意图片条目的物理存储归属
const info = await RBQ.api.gallerySync.inspectImageStorage(currentViewerItem);
console.log(info.type, info.title, info.path, info.color);

// 2. 将任意图片 Blob 压缩为优化版 WebP Blob
const webpBlob = await RBQ.api.gallerySync.createOptimizedWebpBlob(rawBlob, 768, 0.8);

// 3. 上传任意 Blob 到酒馆服务端并获取相对路径
const serverPath = await RBQ.api.gallerySync.uploadBlobToServer(blob, 'my_image.png');

// 4. 对指定历史条目触发收藏原画同步
await RBQ.api.gallerySync.syncFavoriteOriginal(historyItem);

// 5. 获取当前云同步运行时设置
const syncStore = RBQ.api.gallerySync.getStore();
```
