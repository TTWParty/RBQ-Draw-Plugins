# 原版 v1.1 与 SDT 漫画模式适配对照

本次对照源为用户下载目录中的 `v1.1.json`，包含 71 项提示词及开关配置。此表记录漫画模式 1.6.4、SDT 6.2.8 的适配；后续 1.7.0 / SDT 6.3.0 增加了按可见部位组装记忆的程序逻辑，见[当前版本说明](rbq-manga-mode.md)。原文件是酒馆预设，涉及宿主资料注入和外部脚本；没有据此假定原版脚本的运行实现。

## 按职责对照

## 分镜措辞的来源澄清

原版经典四格明确要求“严格起承转结”，并要求依据剧情自适应；原版喜剧日常明确包含笑点、吐槽和表情反差。这些是各自选中风格的要求，不是所有漫画页的通用要求。

此前插件四格指令中的“第三格突发转折，第四格引爆反差包袱或搞笑落点”是适配时的扩写，原版没有这句。此前插件通用映画近景示例中的 `looking at viewer` 在原预设中没有出现；它是有引导偏差的示例，不能准确称为显式的“强制看向读者”规则。

本轮修改保留四格的起承转结和喜剧模式的风格特征，收回额外扩写与错误视线示例。不能把这些插件措辞归因于原预设本身。

## SDT 自有功能与原预设的区别

原预设的工作用角色 DNA 不等于 SDT 的聊天持久档案。SDT 在同一次解析中额外返回 `character_memory`，有开关、首次建档、衣柜及旧楼更新保护；已有非空 base 默认锁定，需使用主动重新提取来修正不完整档案。无名配角可以出镜，但不因此长期建档。漫画工作台读取资料，不从分镜反写聊天记忆。

原预设要求使用本轮可见资料，并没有 SDT 的“首次描述取前 1200 字”设置；之前移除的描述和世界书条目截断属于 SDT 数据收集层。世界书仍受启用、关键词等原有筛选规则影响，并非无条件注入全部世界书。

SDT 还要处理缓存重绘、画廊、手动编辑与测试生图，这些不能从预设文本推断出原版做法。已有回归测试覆盖这些入口；本版额外修复工作台人数统计，按身份汇总全页明确主体标签，避免最后一次局部镜头丢失主体或误读动作对象。

## 验证边界

本地测试验证接口结构、字段传递、槽位、坐标、记忆开关、渲染词与长期颜色隔离、失败处理和请求次数。模型是否正确选材、给出几页、还原动作和中文，需要实际同楼重解析后比较；不能把人工构造页格的测试当成模型质量评测。

提示词更新不会自动重写已有漫画页；重绘复用旧页，重新解析才重新决定剧情分配。当前手头对照的是原预设文件，不是原版脚本运行日志。
