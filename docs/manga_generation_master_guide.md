## 二、画格几何学：面积预算与版式拓扑法则

### 1. 黄金主格（Hero Panel / 決めコマ）绝对统治律
- **面积铁律**：一页必须有且仅有 **1 个核心主格，占据整页 45%～65% 面积**。
- **主格定位**：承载全页决定性时刻（重大动作爆发、核心体态呈现、关键台词宣告、惊人反转）。
- **辅助格定位**：占 10%～25% 面积，承担动机铺垫、次要动作、环境交代或局部反应。
- **严禁均分**：五五开（2格平分）、三等分（3格横切）、四等分（机械四格）会导致视觉焦点涣散，画面彻底失去戏剧张力。

### 2. 画格容量与格数预算（Panel Budget）
单页格数取决于叙事密度与画布尺寸（通常为竖版 832×1216 或横向跨页）：
- **1 格（Splash Page / 一枚絵）**：重大事件定格、极度震撼、章节封面级大场景。
- **2 格（Dynamic Split 7:3 / 6:4）**：因果对决、动作发起与受击、极度紧张的二元博弈。
- **3 格（Setup-Climax-Reaction）**：叙事标准节奏，1 铺垫 + 1 大主格 + 1 反应。
- **4 格非对称（Standard Manga Page）**：商业日漫连载主力结构（1 黄金主格 + 3 节奏辅助格）。
- **5~6 格（High-Density Action / Dialogue）**：极快节奏连招、多人密集辩论交锋。**注意：格数越多，每格人物细节与文字量必须按比例压缩，小格严禁塞长台词。**

### 3. 日漫标准反 Z 字视线动线（Reverse-Z Flow）
日漫从右往左翻页，视线流引导法则：
```
[右上：格1 初始视线切入] ───> [右中：格2 动作突进/阻断]
            │
            ▼
[左侧或横向：格3 黄金大主格 (占据视野重心与情绪高潮)]
            │
            ▼
[右下或左下：格4 情绪收束/悬念钩子 (引导翻至下一页)]
```

## 四、画框语言：出血、斜切与破框（Gutter & Border Dynamics）

商业漫画的画框不是被动的容器，而是情绪与速度的催化剂：

### 1. 经典边框模式（Gutter Styles）
- **全封闭白边（Fully Framed）**：`white border, fully framed panels`。四周带标准白边，格线分明。用于日常、文戏、严谨推理。
- **天地出血（Top-Bottom Bleed）**：`top-bottom bleed, narrow gutters`。天头地脚贴边无白边，内框紧凑。现代连载标准版式，沉浸感极强。
- **全幅粗墨线（Zero-White Border）**：`太い黒い仕切り線, 余白なし, tight panels`。无白色间隙，纯墨线切分，压迫感与对比度极高。

### 2. 动态斜切格（Slanted Panels / 斜めコマ）
- **提示词**：`slanted panels, dynamic angled frame, diagonal gutters`。
- **作用**：边框倾斜打破垂直重力感。用于：突发遇袭、高速冲刺、身体倾斜、情绪失控。

### 3. 破框法（Breaking the Frame / コマぶち抜き）
- **提示词**：`breaking the frame, dynamic foreground, weapon breaking border`。
- **作用**：角色肢体（拳脚、长发）或武器、光效突破外框边界，侵入相邻画格或留白区，产生跃出纸面的 3D 冲击力。

### 4. 回忆格与内心世界（Flashback & Mental Space）
- **提示词**：`black gutters, black border around panel, negative space`。
- **作用**：画格外部使用黑色底色填充（或虚线边框），直观标识时间线跃迁（回忆）或角色深层内心精神空间。

## 六、多角色物理接触与肢体动作工程学（The Action & Limb Engineering Masterclass · 融合 SDT V23/V40 核心神技）

在生成漫画或插画时，最常遇到的挫败就是**“动作僵硬、四肢变形、两人各摆各的 Pose 假装在互动”**。很多时候并非大模型不懂剧情，而是分镜给出的提示词违背了 AI 扩散模型的物理受力与视觉注意力机制。本章深度融合 **SDT V23（国籍面相版）与 V40（全息分层优化版）** 中经过数万次实战沉淀的动作生成绝技，建立一套严密的动作工程体系。

### 1. 动作崩坏与站桩失联的底层原因
1. **注意力分散（Attention Split）**：在 Character Prompt 模式下，如果只在各自的角色槽写单独动词（A: `standing`, B: `punching`），扩散模型会将交叉注意力头分别分配到画布左右两侧，导致“两人中间隔着银河”的各摆各 Pose。
2. **动词权重匮乏（Verb Starvation）**：扩散模型是基于名词/视觉实体训练的（发色、衣服、五官等名词先验极强）。如果动词使用 1.0 默认权重，动作信号会被强大的角色外观词直接吞噬淹没，导致人物退化为呆板的立绘站姿。
3. **肢体模糊与手部粘连（Hand Confusion）**：只写 `both hands gripping`，AI 无法判断两只手的具体受力支点，极易生成黏在一起的肉团、或者凭空画出第 3 只手。
4. **缺乏受力反作用与生理反馈（Missing Reaction & Strain）**：只有“动作”没有“痕迹”，AI 就会画成“手悬空贴在衣服表面”。真实的激烈互动必须靠肉体形变、皮肤凹陷、体液喷溅反向约束四肢。

## 九、同人本 / 感官漫画专门导演学与八页推进链（Eromanga Aesthetics & 8-Page Scene Arc）

### 1. 「无遮挡构图律」（Simultaneous Visibility）
同人本严禁“男方后背把女方挡得严严实实”。必须采用以下三大黄金夹角：
- **过肩侧俯视（Over-the-Shoulder 3/4 High Angle）**：从肩膀侧上方俯瞰，**同时看清女主角面部表情与身体接触部位**。
- **贴身侧切平视（Dutch Angle Profile）**：镜头贴近地面或床面，45度斜角切入，展现两人体型差与背部弓起的身体曲线。
- **俯视大三角构图（High Angle Overhead Triangle）**：从正上方俯视，两人肢体纠缠、散乱在床单上的长发、褶皱衣物一览无余。

### 2. 「拔コマ」呼吸交替法（Contrast Pacing）
在感官互动的高潮阶段，画格绝对不能单一重复同一姿态，必须严格交替三种画格：
1. **见せコマ（全貌主格 50%~55%）**：展示核心体位、体型悬殊、肢体交缠全貌（`interlocking limbs, disheveled clothes, sweat`）。
2. **抜きコマ A（生理/动作/结合部微距切入 20%~25%）**：极近特写——身体交汇处的接触极近微距（`macro close-up on interlocking physical contact, overlapping silhouettes, body fluids`）、双手死死抓皱床单（`fingers digging into sheets`）、脚趾发白蜷缩（`curled toes`）。
3. **抜きコマ B（面部神态破防 20%~25%）**：脸部大特写（阿黑颜倾向）——眼神迷离上翻、脸颊红晕贴纸、嘴唇微张微喘、泪水与口水（`flushed face, parted lips, heavy breathing, blush stickers, rolling eyes, tears, drool`）。

### 3. 本子三大经典单页蓝图（Blueprints）
- **蓝图 A：【强推 / 逼近 / 破防页】（The Cornering Page）**：右上回眸察觉（15%） + 右中抓扣肩膀 Cut-in（15%） + 左侧单边贯通贴墙体格压制主格（55%） + 右下咬牙屈辱特写（15%）。
- **蓝图 B：【本番抽送型 / 核心推进页】（The Interlocking Page）**：经典三段式闭环：**体位主格（50%） -> 结合部微距（25%） -> 阿黑颜面部破防（25%）**。
- **蓝图 C：【高潮爆发 / 余韵瘫软页】（The Climax & Afterglow）**：上方斜切爆发主格（65%） + 下方横向长条余韵格（35%）。

### 4. 商业级感官场景八页宏观推进链（The 8-Page Scene Formula）
当需要将一段小说或剧本转化为整场 8 页连贯漫画时，遵循以下镜头进阶链：


## 十二、工业级通用 Negative Prompt 母版与零翻车终审清单（Checklist & Negative Template）

### 1. 工业级推荐 Negative Prompt 标准母版
为了防止模型把日漫风格画成拟真 3D、混色插画或破裂画格，建议在生图时使用以下标准负面提示词：

```text
colored, color, full color, 3d, realistic, photorealistic, bad anatomy, deformed limbs, extra fingers, missing fingers, malformed hands, blurry, bad lineart, missing panel borders, broken panels, text watermark, artist logo, bad screentone, messy border
```
*(注意：严禁在 Negative Prompt 中加入 `comic`, `manga`, `speech bubble`, `text` 等词，否则会直接摧毁画格切分与文字气泡引擎！)*

### 2. 生图前 10 项终审避雷清单
- [ ] **1. 面积统治校验**：是否存在一个占 45%~65% 的绝对黄金主格？（严禁均分）
- [ ] **2. 景别互斥校验**：相邻画格景别是否跳跃？（严禁连续两个中景）
- [ ] **3. 无遮挡构图校验**：双人互动时，是否采用了过肩3/4角、侧切角或俯视，确保表情与肢体清晰可见？
- [ ] **4. 接触熔接校验**：肢体纠缠时，交互动词是否已并入 Base Caption？双人坐标是否紧贴？
- [ ] **5. 特效图层校验**：是否根据动作激烈程度注入了集中线（`focus lines`）、速度线（`speed lines`）或排线（`cross-hatching`）？
- [ ] **6. 符号化表情校验**：面部神态是否使用了具有二次元辨识度的标签（如 `blush stickers`, `shadowed eyes`, `heart-shaped pupils`）？
- [ ] **7. 纯拟音与娇喘标记**：不需要白框的拟音，是否标记为 `SFX: 擬音, 吹き出しなし` 且内容使用纯正日文拟声词？
- [ ] **8. 气泡语法对齐**：`BubbleType` 声明顺序与数量，是否与 `Text:` 中的两空行（`\n\n`）隔开的文本完全一一对应？
