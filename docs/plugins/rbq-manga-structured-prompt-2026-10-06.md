# 结构化对白提示与错误分类修正

日期：2026-10-06。本地版本：漫画 **1.9.28**、SDT **6.5.18**。

## 本次证据

用户截图展示气泡归属错误，却同时显示安全拒答提示。随后提供的模型返回包含 5 页、15 格、25 个格级气泡，其中 18 个为对白/喊话、6 个拟音、1 个旁白；全部人物 `bubbles` 为空。气泡仅有 type/position/layout/text，没有可用于确定说话者的 ID。

这说明该次模型将格级当成统一的文字容器，生成结果与要求的嵌套归属不符。具体原因仍需要完整请求与解析模型信息确认。只检查结构，不复用用户剧情进行生成、润色或模型测试；回归采用普通办公、递信与对话。

## 提示检查与调整

实际检查共享系统指令、五种规划、角色卡/记忆追加模块、工作台和各请求接口，没有发现结构化模式中直接要求把可见人物对白写入格级的规则。旧格式 positive/Text 输出要求通过选项分支隔离。

确认的薄弱点与修正：

| 原表达 | 本次调整 |
| --- | --- |
| `positive=...，bubbles=[...]` 零散例子没有完整父子对象 | 完整双人问答 JSON；页级、格级 bubbles 为空，各人物分别持有问句和答句 |
| 模型需从长规则自行推导先后顺序 | 明确按正文确定说话者 → 对应画格及 character_id → 本人 bubbles → 气泡形状/位置 |
| 工作台最后的人物字段枚举遗漏 bubbles | 结构化分支补上 bubbles，并再次明确它位于人物对象内 |
| 最终核对笼统允许画外声在 panel/page | 分开整页旁白/拟音、本格非人物文字及真正画外声、人物对白/心声 |
| 结构化分支解释编译后的唯一末尾 Text | 移除模型不需执行的编译说明，输出结构化 JSON 即可 |

普通可见人物问答时 `panel.bubbles=[]`；喊叫、耳语、长句与多泡不改变说话者归属。画格若同时有拟音、旁白或真正画外声，仍可放入格级，不要求所有画格为空。示例适配中文/日文与彩色/灰阶，仅示范字段关系，不控制实际剧情、人数、页数或格数。

共享指令修正覆盖 SDT JSON、工具调用、自定义 HTTP、工作台及现有五种规划。旧格式对白保留所选 Text 协议，四份历史规划原文保持不变。用户自定义后置提示仍按原机制附加，需通过实际请求检查其是否与输出合同冲突。

## 错误处理

归属校验错误使用 `MANGA_BUBBLE_OWNERSHIP`，消息只显示错误数量、前四个位置和修正方向；完整问题列表与模型页树仍可在调试详情检查。

旧诊断通过扫描整个原因和原始剧情寻找“抱歉”、安全关键词，可能把有效 JSON 中的普通对白误判为拒答。现在先识别字段错误，再依据明确错误原因及服务商 finish/block/refusal 元数据区分真实安全拒答。普通正文关键词不再单独触发该分类。字段问题的提示指向核对结构和说话者；拒答的提示指向服务商规则和返回原因。

本次仍保留归属检查兜底，程序不会凭气泡左右位置、人物排列或仅有一个可见人物就猜测并搬移台词。本次返回缺少明确说话者引用，无法无歧义地自动修复全部归属。

## 验证范围与后续方向

新增真实请求构建回归，检查实际发送的完整双人示例，并由生产校验/编译/NAI 请求钩子确认问答分别保留在对应人物字幕；覆盖五种规划、两种色彩、角色卡/记忆开关、JSON/工具/自定义 HTTP、工作台和旧格式选项。另有错误分类、真实主界面异常处理及 18 处错误摘要检查。

最终 **32 个漫画与 SDT 回归脚本、707 项检查全部通过**，包括新增 7 项请求提示测试、8 项分类测试，以及 18 处错误摘要与主界面分类保留检查。生产文件和新测试语法、版本清单与差异检查通过。

全部接口响应使用普通模拟数据，未调用真实解析模型或生图服务。它证明发送给模型的指令与示例正确、相互一致，不能证明模型实际遵循率。

若要进一步减少层级误放，可引入共享对白清单、来源引用及明确 speaker_id，页格只引用对白 ID，再由程序按照已确认的说话者归属编译。这需要单独处理长句分泡、跨页、翻译、真实重复对白和历史草稿兼容。若要求准确画字及气泡位置，还需本地文字叠加与明确版面坐标；这些都未在本次实现。
