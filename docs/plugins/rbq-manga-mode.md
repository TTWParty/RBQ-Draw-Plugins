# 漫画模式 (Manga Mode)

插件 ID：`rbq-manga-mode`

入口文件：[`../../plugins/manga-mode.js`](../../plugins/manga-mode.js)

版本：`1.0.0`

---

## 🚀 核心特性 (v1.0.0)

- **🎬 智能生图插件（SDT）深度原生融合**：
  - 在 SDT 设置面板的「提示词风格预设 (Prompt Presets)」旁边无缝挂载「漫画模式」专属开关卡片。
  - 开启漫画模式后，**自动锁定并接管原有普通预设下拉框（变为不可选）**，展开专属的漫画画风、分镜文法、对白气泡与留白排版控制台。
  - 关闭漫画模式时，一键平滑复原原有的提示词预设与设置。
- **🎨 4 档专属漫画画风 + 自定义画风库**：
  - **经典黑白网点漫 (Monochrome Screentone)**：还原实体日漫单行本质感，注入细腻网点纸（screentone）、粗墨线（bold linework）与灰阶光影，全自动压制反色词。
  - **柔光全彩赛璐璐 (Soft Cel Shaded Anime)**：精选自经典分镜预设，剧场版柔和色彩与温润肤色（amber tones, cel shaded anime characters），保持通透二次元动画质感。
  - **现代彩色条漫 (Webtoon Aesthetic)**：鲜明活泼的现代全彩漫画与条漫质感，线条干净工整、光影柔和。
  - **热血高张力黑白 (Shonen Action Comic)**：粗犷重墨线、速度线与高反差冲击张力。
  - **⚙️ 自定义画风 (Custom)**：可自主输入正面画风 Tag 串与针对性负面词。
- **📹 8 大剧情分镜文法切换**：
  - 通用映画文法、经典四格 (4-Koma)、少年热血、悬疑推理、恋爱少女、轻松日常、喜剧搞笑、本子肉感。
- **💬 原生对白与气泡契约（NAI V5 核心语法）**：
  - 自动识别语气并映射对应气泡：`通常吹き出し`（普通对白）、`叫び吹き出し`（怒喊/高声）、`思考の吹き出し`（心声独白）、`ナレーション枠`（客观旁白框）、`擬音, 吹き出しなし`（拟声拟态词）。
  - 支持 **🇨🇳 简体中文** 与 **🇯🇵 日文原版** 自由切换，严格按日漫纵向从右向左阅读排版（`Layout: 縦書き`）。
- **🛡️ 负面词智能安全净化**：
  - 自动过滤并剔除负面词中会扼杀漫画分镜的禁忌词汇（如 `comic, comic panels, speech bubble, screentone, text` 等）。
- **📖 智能横向跨页自适应 (見開きページ)**：
  - 遇到宏大场景或双页跨页时，自动将出图分辨率从竖屏（832×1216）翻转为横幅大宽屏（1216×832）。
- **🦑 同人角色防夺舍 (Anti-Franchise Hijack)**：
  - 隔离同人角色的官方立绘画风，防止选定的黑白漫画风格被角色自带游戏立绘画风冲淡。
- **🛡️ 绿色生命周期与热插拔守卫 (`Lifecycle Cleanup`)**：
  - 支持插件中心即时卸载与热更新，自动解绑 DOM 监听并无痕还原 SDT 原有设置。

---

## 🌟 使用方法

1. 在 **RBQ 插件中心** 搜索或安装 `漫画模式 (Manga Mode)`；
2. 打开 **“智能生图触发器 (SDT)”** 的设置面板，切换到 **「🎭 提示词与破限」** 页面；
3. 在顶部的 **「提示词预设档位」** 下方，直接点击打开 **「漫画模式」** 开关；
4. 普通提示词预设会自动置灰锁定，下方展开漫画专属画风（黑白网点/全彩漫等）与分镜文法选项；
5. 在酒馆中正常聊天或跑团，生成的插图即刻转化为**带有对白气泡与分格效果的真实日漫连载页**！
