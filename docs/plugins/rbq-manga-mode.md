# 漫画模式与漫画工作台

插件 ID：`rbq-manga-mode`。入口：[manga-mode.js](../../plugins/manga-mode.js)。

版本：**1.6.2**，配套智能生图（SDT）**6.2.2**。更新时请确认两个插件均为上述版本或更高，并刷新酒馆。

## 1.6.2：文字格式与通用动作表达

对照原预设 v1.1.json 的「气泡:边框形状」「文字:演出契约」和「语法:输出协议」，沿用原文字格式：视觉标签、气泡类型、位置和 Layout 写在前面，末尾只用一个 Text:，后面只放实际原句。同人多句用空行分隔，不复制人物槽。示例：

```text
top panel, girl, holding envelope, BubbleType: 通常吹き出し, 右上, Layout: 縦書き
Text: 信收到了。

谢谢。
```

本地文字整理会修复明确的错误结构，例如 `Text: 通常吹き出し, Layout: 縦書き, Text: 信收到了。`，把格式头移到台词前；去除独立整句外包的「」或引号。句内真实引用和普通台词中出现的 Text/Layout 等字样保留。整理作用于页面编译及发送前，因此已缓存的格式错误也可在重绘时修复；缺失的台词不会被程序编造，须重新解析或手动补充。

提示词明确区分可见人物对白、画外声、旁白和拟音。需要上画的文字实际写进 Text，不能只写 speaking/speech bubble；静默格不要求空白气泡。模型对文字归属和漏字的判断仍需实际出图核对。

参考 v23、v24、v40 的通用标签规则，绘图字段要求以英文逗号分隔的标签为主；人物按位置、可见外貌衣着、基础姿势、肢体及接触对象、表情视线组织。自然语言仅用于紧邻标签的短关系补充。新增递信的非露骨动作示例，约束多人物动作归属、可见性、互斥姿势和闭合短词组权重。没有恢复旧预设的固定页数、每页标签配额或额外分析请求。

## 角色外貌记忆

SDT 6.2.2 恢复漫画模式的新角色建档和衣着更新。开启 SDT 的角色外貌记忆后，同一次 Tagger 响应增加简短的 `character_memory` 数组，每人一项 `{name, base, outfit}`。资料使用原有的聊天独立角色档案和衣柜，新角色会出现在原有角色列表中。

- `name` 与格内人物的稳定姓名对应；同一人物跨格跨页只学习一次，C1、P1、空镜和匿名路人不建档。
- `base` 用于新建外貌或填补空档案。已有非空外貌保持原值；模型根据资料为每格选取可见特征，程序不把整份档案强塞回特写。
- `outfit` 仅在首次着装或明确变化时提交完整已知衣着，空字符串保留已有着装。提示词要求使用本楼最后出场时的状态，不把裁切视野当作换装。不同服装沿用原有衣柜归档逻辑。
- 外貌资料与漫画画风分别处理，黑白画面仍可保存已知发色、瞳色供后续复用。资料不从混有动作、气泡和对白的 `positive` 自动拆取；带 `Text/BubbleType/Layout/SFX` 的记忆字段会被跳过。
- 页格全部解析成功后才写记忆。重新解析较旧楼层时，不覆盖漫画模式已记录的较新楼层着装。模型仍需正确区分完整着装与局部可见衣物，程序无法判断所有标签的语义。

仅在记忆开关开启时增加该输出要求，没有额外请求或自动重试。模型漏返回记忆资料时保留有效漫画页、跳过这次学习，可在原始输出中检查 `character_memory`。已缓存的旧漫画需重新解析才会建档，直接重绘不会重新学习。

## 本楼剧情如何变成漫画

SDT 在同一次 Tagger 请求中先规划、后填写绘图词：

1. **承接状态**：历史只提供进入本楼时仍有效的身份、场所、衣着、持物和接触状态。本楼发生的变化按顺序更新，后文的换装不会提前应用到前面的格；角色档案和衣柜不能覆盖已经发生的变化。自动解析只传入目标楼层之前的历史，避免重解析旧楼时混入后续剧情。
2. **选择剧情**：扫描本楼开端到结尾，选择登场、重要动作与结果、关键对白、情绪变化、线索和转场。重复的小动作可以合并；没有新信息的寒暄、纯抽象议论和未发生的假设不需要硬画。没有大动作的告白、拒绝等关键对白仍然可以画。
3. **安排页格**：每个 `segment` 是一张最终图片。先安排画格，再按动作、人数、文字容量和叙事停顿组合成页。普通页 2～5 格仅作容量参考，单格页合法；长对白和复杂互动可跨页。普通插画的“最少分镜数”和 `[图组]` 标记数量不再强制决定漫画页数。
4. **确定每页内容**：每页可用 `intent` 简述主画面、叙事任务和分页理由；各格指定阅读位置、景别、一个相容的定格时刻、可见人物与对白。文法作为演出偏好，不为热血风格强加斜切格，不为四格编造剧情。

### 1.6.1：减轻解析负担

取消 1.6.0 的强制 `story_plan`、逐字 `source`、`beat_ids` 覆盖报告及整次规划修正重试。模型直接提交最终页格，不再因节点引用有标点/措辞差异或排序差异而报“漫画规划校验失败”。收到旧版附带的节点清单时也不以它阻断有效漫画页。

保留前情承接、剧情选择、分页和对白规则，将前情增强缩为简短指令。`intent` 为可选的一句话说明，缺失不报错；可在现有卡片调试详情中查看。页数按实际 `segments` 数量计算。

程序仍检查可渲染的页面结构、人物数据及有效坐标，避免把损坏数据传给绘图模型。引用措辞变化交给现有锚点定位逻辑处理，不触发额外 Tagger 请求。本次移除的是漫画规划重试，接口原有的格式兼容/流式降级逻辑保持不变。

最终选材、对白可读性和画质仍需用实际 Tagger/绘图模型做对照；本次没有测量真实接口延迟。

## 这一版改变了什么

漫画使用“页面 → 画格 → 格内人物”结构。同一格可以有多人，一个人可以跨格多次出场；空镜不创建人物槽。画格数与人物出场槽数分别计算。

聊天自动解析、手动描述生图、工具调用及漫画工作台共用漫画协议。逐人物正负词在最后发送时展平成 NAI `char_captions`，不再通过“一个画格等于一个角色”组织请求。

- 页面及画格的环境、旁白、拟音、画外对白进入全局 caption；可见人物的动作和对白进入本人 caption。
- 各字段的视觉说明排列在 `Text:` 之前，台词和多气泡空行保留，外层对白引号按原预设剥除。台词里的逗号、竖线和 `no text` 不参与标签清理。
- 分页依据事件、文字量和画格容量，允许单格大画面。经典四格保留均等画格，不再与全局“禁止四等分”指令冲突。
- 角色记忆和世界书是导演的资料输入；最终镜头描述不会被整份全身外貌档案覆盖。
- 负面清理以完整标签及闭合权重块为单位。原作排除词由导演根据资料明确填写，不从任意括号猜测作品名。
- 请求顶层 `model` 设为 `nai-diffusion-5-full`。横向跨页只检测视觉描述，不检测台词。
- **Prompt Presets 插件的画风拼接保持现有行为。**

## 使用

在 SDT 的提示词设置中开启漫画模式，或直接进入独立的“漫画工作台”。关闭漫画模式时会恢复启用前的 SDT 提示词、自定义预设、前情分析及多角色设置。

工作台支持 1～5 格：

1. 输入剧情后使用“AI 智能分镜推演”，或逐格输入剧情后批量解析。
2. 设置各格的位置、大小、景别与环境。
3. 展开“格内人物与文字”，分别编辑每个人的身份编号、姓名、镜头描述、对白及负面词。同一人物跨格使用相同身份编号。
4. 旁白、拟音和画外文字放在单独的非人物文字栏；空镜保留零个人物。
5. 检查组装预览后生成。静默格与有对白的格子使用同一组装流程。

工作台 AI 使用 SDT 的 OpenAI 兼容接口配置。接口未配置、调用失败、JSON 无效或格数不符时保留当前分镜并提示错误，不再用猜测剧情自动替代。经典四格须选择自动或 4 格。

格子的增删、复制或移动会重新安排默认位置，之后可手动调整位置和大小。人物编辑区按需展开，支持手机端纵向编辑。

## 数据协议

每个 SDT `segments[]` 是一个漫画页：

```json
{
  "format": "nai5-comic",
  "label": "Page 1: 放学后",
  "intent": "两人约定同行，以对话为主格、离开后的空教室收尾，同页完成。",
  "anchor": { "text": "她们交谈后转身离开了教室。" },
  "page": { "base": "comic, 2 panels, 2girls, vertical layout" },
  "panels": [
    {
      "id": "P1",
      "description": "top panel, classroom, medium shot",
      "characters": [
        { "character_id": "C1", "name": "甲", "positive": "top panel, girl, long hair, BubbleType: 通常吹き出し, Layout: 縦書き, Text: 一起回家吧。", "negative": "short hair" },
        { "character_id": "C2", "name": "乙", "positive": "top panel, girl, short hair, BubbleType: 通常吹き出し, Layout: 縦書き, Text: 好。", "negative": "long hair" }
      ]
    },
    {
      "id": "P2",
      "description": "bottom panel, empty classroom",
      "non_character": "bottom panel, SFX: 擬音, 吹き出しなし, Text: 咔哒",
      "characters": []
    }
  ]
}
```

默认自动定位。导入的手动定位页可用 `position_mode: "manual"`，每次人物出场需填写有效 `center: {x, y}`（0～1）。编译器检查画格 ID、同格重复人物、正负词字段及手动坐标。

上例是单页结构；SDT 顶层响应为 `{ "shouldDraw": true, "segments": [...] }`，可附简短 `reason`。无需节点清单或原文覆盖报告。文本 JSON 与工具调用使用相同页格结构。

## 已有数据

不会自动删除或改写已保存的分镜、模板或角色档案。旧版工作台混合标签保留为页面内容，不猜测人物身份；点击“AI 润色本格”或批量解析后转换为新结构。新版内置模板已明确拆分人物与环境。

SDT 已缓存的旧分镜继续使用旧数据重绘；重新解析时要求新协议。漫画页换装通过 AI 微调按人物出场更新，避免字符串拼接同时保留新旧衣服。
